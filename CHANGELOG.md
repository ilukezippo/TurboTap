# Changelog

## 1.0

First release.

- Rapid-fire for keyboard keys, mouse buttons and game controller buttons, 1-50 taps per second
- Hold or Toggle (auto-tap) mode, press length and human-like randomize
- Reads PS5 DualSense, PS4, Xbox, Switch Pro and generic controllers (USB or Bluetooth)
- Controller turbo through a virtual Xbox 360 controller, with one-click ViGEmBus and HidHide setup
- Tester with live keyboard, mouse and controller views where you can watch the turbo work
- Only-in-this-game option, F8 on/off hotkey with sounds, profiles
- Checks GitHub for updates on startup and from the About tab
